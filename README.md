Dip-buy sniper for the pump.fun paper sprint: buy a new curve once at 0.01 SOL after it pumps >=15% off create then retraces >=30% off its peak (real reserve 2-5 SOL, first trade >=1 SOL, within 600 slots). Exit at +30% take-profit, -5% stop-loss, a -8% trailing drop off a +10% peak, or age >200 slots. Deterministic, no network, no secrets.

## Run it

```sh
node main.ts
```
